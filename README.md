# SOLO 数据工程本地实现

按单题题面实现功能、自行生成合成输入，交付可复跑的源码与结果。

## 子仓

- `audiomix/`：多采样率剪辑时间轴与真实混音档案（不可变发布产品、内容寻址
  块仓、逐块追溯；只消费产品与实际素材字节）。
- `tourbox/`：巡展跳听盒差分母带成品仓。把已渲染 PCM 连同原 render、采样范围
  与来源身份封版为可离线核对的流式交付（两类记录：宽整数差分 / 绝对复位），
  提供复位点布局精确优化、销售计划封版、设备逐卡自包含复播与具名 clip 锚点。
  核心代码纯标准库；仅旧仓适配器可选依赖 numpy。
  入口：`cd tourbox && bash run_all_checks.sh`
